# OpenTiny 社区活动资料

[English](./README.md) | 简体中文

本仓库用于集中收录 OpenTiny 社区活动资料，方便社区成员查找、使用和分享。

## 资料内容

仓库可能包含以下类型的资料：

- 活动手册与日程
- 演讲幻灯片与直播资料
- 赛题说明与 Demo 项目
- 参考文档及其他配套材料

活动资料按活动名称和年份整理在 `events/` 目录中。每个活动目录应包含一份 README，用于介绍资料内容及使用方式。

```text
events/
└── <活动名称>-<年份>/
    ├── README.md
    └── <活动资料>
```

## 使用资料

1. 打开 `events/` 目录。
2. 选择需要查看的活动。
3. 阅读活动 README，了解活动概况、资料链接和使用说明。

你可以直接在 GitHub 上浏览文件，也可以克隆仓库到本地：

```bash
git clone https://github.com/opentiny/community-resources.git
cd community-resources
```

## 参与贡献

欢迎提交新的活动资料，或改进已有内容。

1. Fork 本仓库并创建新分支。
2. 在对应的活动目录中新增或更新资料。
3. 提供 README，介绍活动并列出所包含的资料。
4. 创建 Pull Request，并清晰说明本次变更。

提交前，请确认你有权分享相关资料，并避免提交敏感信息或体积较大的生成文件。
