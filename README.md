# OpenTiny Community Resources

English | [简体中文](./README.zh-CN.md)

This repository collects materials from OpenTiny community events and makes them easy to find, use, and share.

## Resources

Materials may include:

- Event guides and schedules
- Presentation slides and livestream resources
- Challenge descriptions and demo projects
- Reference documents and other supporting materials

Event resources are organized under `events/` by event name and year. Each event directory should include a README that describes its contents and how to use them.

```text
events/
└── <event-name>-<year>/
    ├── README.md
    └── <event-resources>
```

## Using the Resources

1. Open the `events/` directory.
2. Select an event.
3. Read the event README for an overview, resource links, and usage notes.

You can browse files directly on GitHub or clone the repository:

```bash
git clone https://github.com/opentiny/community-resources.git
cd community-resources
```

## Contributing

Contributions of new event materials and improvements to existing resources are welcome.

1. Fork this repository and create a branch.
2. Add or update resources in the appropriate event directory.
3. Include a README that explains the event and lists the included materials.
4. Open a pull request with a clear summary of your changes.

Please make sure that you have permission to share all submitted materials and avoid committing sensitive information or large generated files.
